# 观阅轨迹

> 记录看过的书、电影、动漫、电视剧的个人收纳 App。纯本地存储，离线可用，无需登录。
> 先是一个好用的「记录本」，再是一个能和朋友交换轨迹、发现好作品的「社交工具」。

## 一、记录本身（核心基础）

先把「记录」这件事做好，这是软件的根。

- **四类内容**：书 📖、电影 🎬、动漫 🎐、电视剧 📺
- **标记状态**：想看 / 已看，想看详情页一键「标记为已看」；好作品可以累计记录**重看次数**
- **5 星评分** + **看完时间**（按类型显示不同文案：书「掩卷于」、电影/电视剧「落幕于」、动漫「定格于」）
- **电影专属**：记录观影方式（居家观影 / 影院观影）+ 共同观影人
- **类型标签**：自由打标签，标签库按类型隔离、可复用
- **搜索**：按名称 / 标签搜索，可限定类型
- **一句话备注**：写几句自己的短评

## 二、好友分享交流（核心亮点）

把自己的「看过」变成可以交换的「社交货币」。

### 1. 分享：想发多少就发多少，粒度由你掌控
- **分享单条**：任意记录详情页，一键打包分享这一部
- **分享部分**：首页长按多选，勾选几部凑成「精选合集」再发
- **分享全部**：一键把整个书影音库打包

分享文件是标准 JSON，**自动带上你的用户名**（设置里填写，最多 16 字），走系统分享面板，可发微信、网盘、存文件，跨平台都能传。

### 2. 导入：好友的文件直接「走进」你的 App
在「好友轨迹」区导入，用文件管理器挑好友发来的文件；解析后自动识别好友用户名，**按好友名分栏归档**。

### 3. 好友轨迹：两级结构，井井有条
打开先看**好友列表**（按用户名分栏）；点进好友，展开 TA 的**具体轨迹**，每条记录的类型、评分、标签、备注都完整呈现。

### 4. 覆盖更新：好友重新发了怎么办？
导入时检测到同名好友会弹出选择：**覆盖更新**（整体替换）或**追加合并**（新旧都保留）。

### 5. AI 对比分析：把「撞片」变成「懂彼此」
点开好友进入 AI 分析，以**第三人称客观口吻**生成系统、精炼、条理清晰的对比报告，分四段：

1. **好友的偏好画像** —— 从 TA 的作品类型、题材、风格、评分推断口味
2. **轨迹重合度** —— 明确列出共同看过的作品，判断重合度高低
3. **相近偏好** —— 概括你俩的共同兴趣倾向
4. **推荐** —— 从「好友看过、你没看过」的作品里挑 2~3 部最可能合你胃口的，各附一句理由

## 三、AI 补全

编辑页接入 DeepSeek，输入作品名 + 类型，一键补全作者/导演、主演、简介、版本、标签。

## 四、其他

- **备份**：导出/导入全部数据为本地 JSON，换机不丢记录
- **清爽莫兰迪 UI**：低饱和青灰色调，简洁耐看，带开屏页
- **纯本地存储**：SQLite，无后端、无账号、无联网依赖，隐私完全在自己手里

- Flutter 3.x + Dart 3
